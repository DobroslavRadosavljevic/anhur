MDX and Markdown bodies are large. Shipping every body on the blog index hurts performance and bundle size. Anhur’s default **`light`** split keeps lists lean and loads full documents on demand.

## Default behavior

For a collection named `posts`:

```ts
import { allPosts, getPost } from "anhur/generated";

// Index route — no body by default
allPosts.map((p) => ({ title: p.title, slug: p.slug }));

// Detail route — full document (string id/slug or query object)
const post = await getPost("hello");
// or: await getPost({ locale: "en", slug: "hello" })
if (!post) {
  // missing — getters return null
}
```

`listOmit` defaults to `["body"]` for light lists. Keys that are not on the schema/documents are skipped, so YAML authors without `body` stay typed as `Author`, not `Omit<Author, "body">`. Override with `generate.listOmit`.

## Split modes

| Mode              | List                       | Per-doc modules | Getter   |
| ----------------- | -------------------------- | --------------- | -------- |
| `light` (default) | Omits `listOmit` fields    | Yes             | Yes      |
| `full`            | Full documents in the list | Optional / none | Optional |
| `list-only`       | Everything in the list     | No              | No       |

Use `list-only` for small YAML/JSON catalogs where every field is cheap. Keep `light` for MDX/Markdown collections. For large catalogs that still need detail lookup or facet pages without a getter, add [`defineIndex`](/reference/define-view) / [`defineGroup`](/reference/define-view) under `views`.

When a light list omits fields (default: `body`), the same keys are stripped from **embedded** documents too (`s.reference(..., { embed: true })`). Full documents from getters keep embedded bodies.

```ts
defineCollection({
  name: "products",
  directory: "content/products",
  include: "**/*.json",
  localized: false,
  generate: { split: "list-only" },
  schema: s.object({
    sku: s.unique(),
    name: s.string(),
    price: s.number(),
  }),
});
```

## Lookups

Getters resolve by id and, by default, slug. Add keys with `generate.lookupBy`.

## Types

```ts
import type { Post, PostListItem, Posts } from "anhur/generated";
```

`PostListItem` is the light row shape; `Post` is the full document.
