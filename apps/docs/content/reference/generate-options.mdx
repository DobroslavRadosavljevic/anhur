## Collection `generate`

| Option                  | Default / notes                                                           |
| ----------------------- | ------------------------------------------------------------------------- |
| `split`                 | `"light"` \| `"full"` \| `"list-only"`                                    |
| `listOmit`              | Default `["body"]` for light lists                                        |
| `listName`              | e.g. `allPosts` from collection `name`                                    |
| `getterName`            | Default `get${typeName}` (set `typeName` on `defineCollection`, not here) |
| `lookupBy`              | Extra getter keys (slug included by default)                              |
| `emitIds` / `emitSlugs` | Union type exports (`PostId` / `PostSlug` from `typeName`)                |
| `listSort`              | `{ by, order?: "asc" \| "desc" }`                                         |
| Type name overrides     | List item / array aliases only (`listItemTypeName`, `arrayTypeName`)      |

Document type name: `defineCollection({ typeName })`, not `generate.typeName`.

## Singleton `generate`

| Option         | Notes                                 |
| -------------- | ------------------------------------- |
| `exportName`   | Default export name                   |
| `getterName`   | Locale/document getter                |
| `variantsName` | All-locales array name                |
| `split`        | `light` vs `full` / `list-only`       |
| `emitAll`      | Emit all-locales array (default true) |

## View / index / group `generate`

| Option     | Notes                                                      |
| ---------- | ---------------------------------------------------------- |
| `listOmit` | Override inherited light-list omit before `select`         |
| `listSort` | `{ by, order? }`                                           |
| `compare`  | Custom comparator (wins over `listSort`)                   |
| `limit`    | Cap rows after sort (views: whole list; groups: per group) |
| `listName` | Override default `all…` list export (views)                |

Full API: [defineView](/reference/define-view).
