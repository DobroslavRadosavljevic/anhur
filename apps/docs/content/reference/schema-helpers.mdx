## From `@anhur/core` (`schema as s`)

| Helper                          | Output idea                                        |
| ------------------------------- | -------------------------------------------------- |
| `s.raw()`                       | String body / blob                                 |
| `s.slug()`                      | Slug string                                        |
| `s.unique()`                    | Unique value in collection                         |
| `s.reference(name, { embed? })` | String id, or embedded document when `embed: true` |
| `s.isodate()`                   | ISO date string (string or YAML `Date`)            |
| `s.excerpt({ length? })`        | Excerpt                                            |
| `s.metadata()`                  | Metadata object                                    |
| `s.toc({ maxDepth? })`          | TOC entries                                        |

Plus the usual Zod builders: `s.object`, `s.string`, `s.number`, `s.boolean`, `s.array`, …

## Opt-in

| Helper          | Package           | Needs processor |
| --------------- | ----------------- | --------------- |
| `m.mdx()`       | `@anhur/mdx`      | `mdx()`         |
| `md.markdown()` | `@anhur/markdown` | `markdown()`    |
| `a.image()`     | `@anhur/assets`   | `assets()`      |
| `a.file()`      | `@anhur/assets`   | `assets()`      |
