```ts
import { defineConfig } from "@anhur/core";

export default defineConfig({
  content: [/* collections & singletons */],
  views: [/* optional defineView / defineIndex / defineGroup */],
  processors: [/* optional */],
  integrations: [/* orama({…}), defineIntegration({…}) */],
  localization: {
    strategy: "folder",
    locales: ["en", "de"],
    defaultLocale: "en",
  },
  outputDir: ".anhur/generated",
  cacheDir: ".anhur/cache", // or false
  loaders: [/* optional */],
  prepare: (sources) => {},
  complete: () => {},
});
```

Integration factories such as `orama()` get their document types from the inline `content` array — no `defineConfig<typeof content>` required.

| Field          | Required | Notes                                        |
| -------------- | -------- | -------------------------------------------- |
| `content`      | Yes      | Non-empty array of sources                   |
| `views`        | No       | `defineView` / `defineIndex` / `defineGroup` |
| `processors`   | No       | Opt-in MDX / Markdown / assets               |
| `integrations` | No       | `orama({…})`, `defineIntegration({…})`, …    |
| `localization` | No       | Folder locales catalog                       |
| `outputDir`    | No       | Default `.anhur/generated`                   |
| `cacheDir`     | No       | Default `.anhur/cache`; `false` disables     |
| `loaders`      | No       | Extra loaders before built-ins               |
| `prepare`      | No       | After transforms, before codegen             |
| `complete`     | No       | After codegen + integrations                 |

See [Configuration](/guides/configuration) and [defineView](/reference/define-view).
