---
title: defineCollection
description: API for many-document content sources.

  label: defineCollection
  order: 1

```ts
import { defineCollection, schema as s } from "@anhur/core";

defineCollection({
  name: "posts",
  typeName: "Post", // optional; default is singular PascalCase from `name`
  directory: "content/posts",
  include: "**/*.{md,mdx}",
  localized: false, // optional; inherit project localization by default
  optional: undefined, // collections are required sources
  schema: s.object({ title: s.string() }),
  transform: (doc, ctx) => doc,
  onSuccess: (docs) => {},
  generate: {
    split: "light",
  },
  listOmit: ["body"], // prefer generate.listOmit
});
```

| Field       | Required | Notes                                                                                          |
| ----------- | -------- | ---------------------------------------------------------------------------------------------- |
| `name`      | Yes      | Collection id and folder-derived export names (`allPosts`, …)                                  |
| `directory` | Yes      | Content root for this source                                                                   |
| `include`   | Yes      | Glob relative to `directory`                                                                   |
| `schema`    | Yes      | Zod schema                                                                                     |
| `typeName`  | No       | Document type / default getter base (`Post`, `getPost`). On `defineCollection`, not `generate` |
| `localized` | No       | Inherit / `false`                                                                              |
| `transform` | No       | Per document                                                                                   |
| `onSuccess` | No       | After this source’s codegen                                                                    |
| `generate`  | No       | Codegen knobs                                                                                  |
| `listOmit`  | No       | Legacy alias; prefer `generate.listOmit`                                                       |

Snake_case plurals work: `name: "use_cases"` → type `UseCase`, `getUseCase`, `allUseCases`. Override with `typeName` when the auto name is wrong.

See [Collections & singletons](/concepts/collections-and-singletons).
