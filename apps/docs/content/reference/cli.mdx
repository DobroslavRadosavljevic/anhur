Ships with `@anhur/core`.

```sh
anhur build --root .
anhur watch --root .
```

| Flag              | Description                                     |
| ----------------- | ----------------------------------------------- |
| `--root <dir>`    | Project root (default: current directory)       |
| `--config <path>` | Config path if not `anhur.config.ts` under root |

```sh
bunx anhur build --root .
npx anhur build --root .
```

Setup guide: [CLI setup](/getting-started/cli)
