Use schema field helpers for body compilation. Use **`transform`** for joins, permalinks, and other derived data.

## Collection transform

```ts
defineCollection({
  name: "posts",
  directory: "content/posts",
  include: "**/*.md",
  schema: s.object({
    title: s.string(),
    slug: s.unique(),
    author: s.reference("authors"),
  }),
  transform: (doc, ctx) => {
    if (doc.draft === true) return ctx.skip("draft");

    const author = ctx.documents("authors").find((a) => a.id === doc.author);

    return {
      ...doc,
      permalink: `/blog/${doc.slug}`,
      authorName: author?.name ?? null,
    };
  },
});
```

| API                     | Role                                                 |
| ----------------------- | ---------------------------------------------------- |
| `ctx.documents(source)` | Other sources’ documents (definition or name string) |
| `ctx.skip(reason)`      | Omit this document from output                       |
| `draft: true` on data   | Also drops the document                              |

## References

```ts
author: s.reference("authors"); // stores id / key
author: s.reference("authors", { embed: true }); // embed related doc when possible
```

The referenced collection must be registered in `content`.

## Prefer fields for bodies

```ts
// Prefer
body: m.mdx();

// Avoid compiling Markdown inside transform unless you have a special case
```
