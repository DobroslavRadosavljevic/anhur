`@anhur/vite` builds content on `buildStart`, watches files in dev, aliases `anhur/generated`, and can serve copied assets.

## Install

```package-install
@anhur/core @anhur/vite
```

## Usage

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import anhur from "@anhur/vite";

export default defineConfig({
  plugins: [anhur()],
});
```

## Options

```ts
anhur({
  configPath: "./anhur.config.ts",
});
```

| Option       | Default                 | Meaning                   |
| ------------ | ----------------------- | ------------------------- |
| `configPath` | resolved from Vite root | Path to `anhur.config.ts` |

Do not manually alias `anhur/generated` in Vite — the plugin owns it. Still set the TypeScript `paths` entry (see [Project layout](/getting-started/project-layout)).

## Assets middleware

When `@anhur/assets` is configured, the plugin serves files from the assets `dir` at the configured `base` (default `/anhur-assets/`) during development.
