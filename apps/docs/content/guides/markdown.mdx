Use `@anhur/markdown` when a field should become HTML — docs pages, changelogs, and similar content that does not need React inside the body.

## Install

```package-install
@anhur/markdown
```

## Config

```ts
import { defineCollection, defineConfig, schema as s } from "@anhur/core";
import { markdown, schema as md } from "@anhur/markdown";

const pages = defineCollection({
  name: "pages",
  directory: "content/pages",
  include: "**/*.md",
  schema: s.object({
    title: s.string(),
    body: md.markdown(),
  }),
});

export default defineConfig({
  processors: [markdown({ gfm: true })],
  content: [pages],
});
```

## Use the HTML

```tsx
<article dangerouslySetInnerHTML={{ __html: page.body }} />
```

Sanitize if the content is not fully trusted.
