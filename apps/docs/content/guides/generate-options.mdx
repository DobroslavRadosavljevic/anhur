Pass `generate` on a collection or singleton to control how modules are emitted.

## Collection example

```ts
defineCollection({
  name: "posts",
  directory: "content/posts",
  include: "**/*.{md,mdx}",
  generate: {
    split: "light",
    listOmit: ["body"],
    listName: "allPosts",
    getterName: "getPost",
    lookupBy: ["id", "slug"],
    emitIds: true,
    emitSlugs: true,
    listSort: { by: "publishedAt", order: "desc" },
  },
  schema: /* … */,
});
```

## Split modes

| Mode        | Use when                                       |
| ----------- | ---------------------------------------------- |
| `light`     | MDX/Markdown posts — default                   |
| `full`      | You want every field on the list and no getter |
| `list-only` | Small catalogs (products, authors)             |

See [Light lists & getters](/concepts/light-lists-and-getters).

## Naming

| Option       | Default idea                                                 |
| ------------ | ------------------------------------------------------------ |
| `listName`   | `allPosts` / `allUseCases` from collection `name`            |
| `getterName` | `get${typeName}` (e.g. `getPost`, `getUseCase`)              |
| Type names   | From `defineCollection({ typeName })` or singularized `name` |

Put `typeName` on **`defineCollection`**, not inside `generate` (that is a TypeScript error). Example override:

```ts
defineCollection({
  name: "use_cases",
  typeName: "UseCase", // optional when auto-singular already matches
  directory: "content/use_cases",
  include: "**/*.md",
  schema: /* … */,
});
// → UseCase, getUseCase, allUseCases, UseCaseId (when emitIds)
```

Each build clears `.anhur/generated` (or your `outputDir`) before writing, so renamed or removed collections do not leave stale `allX.js` / `getX.js` files.

## Views, indexes, and groups

Derived exports use a smaller `generate` surface (`listOmit`, `listSort`, `compare`, `limit`, optional `listName`). See [defineView](/reference/define-view).

## Singletons

| Option                                       | Notes                                                |
| -------------------------------------------- | ---------------------------------------------------- |
| `exportName` / `getterName` / `variantsName` | Rename exports                                       |
| `split`                                      | `light` vs `full` / `list-only`                      |
| `emitAll`                                    | Emit all-locales array when localized (default true) |
