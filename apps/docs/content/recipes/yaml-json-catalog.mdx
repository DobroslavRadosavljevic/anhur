Small structured data — no Markdown bodies, everything on the list. Use **views** for featured subsets, SKU lookup, and category pages instead of filtering a huge `allProducts` at runtime.

## Install

```package-install
@anhur/core @anhur/vite
```

## Config

```ts title="anhur.config.ts"
import {
  defineCollection,
  defineConfig,
  defineGroup,
  defineIndex,
  defineView,
  schema as s,
} from "@anhur/core";

const products = defineCollection({
  name: "products",
  directory: "content/products",
  include: "**/*.json",
  localized: false,
  generate: {
    split: "list-only",
    listSort: { by: "name", order: "asc" },
  },
  schema: s.object({
    sku: s.unique(),
    name: s.string(),
    category: s.string(),
    featured: s.boolean().optional(),
    price: s.number(),
  }),
});

const featuredProducts = defineView({
  name: "featuredProducts",
  from: products,
  where: (doc): doc is typeof doc & { featured: true } => doc.featured === true,
  generate: { limit: 12 },
});

const productBySku = defineIndex({
  name: "productBySku",
  from: products,
  key: "sku",
  select: (doc) => ({
    name: doc.name,
    sku: doc.sku,
    price: doc.price,
  }),
});

const productsByCategory = defineGroup({
  name: "productsByCategory",
  from: products,
  by: "category",
  select: (doc) => ({
    name: doc.name,
    sku: doc.sku,
    price: doc.price,
  }),
});

export default defineConfig({
  content: [products],
  views: [featuredProducts, productBySku, productsByCategory],
});
```

## Usage

```ts
import {
  allProducts,
  allFeaturedProducts,
  productBySku,
  productsByCategory,
} from "anhur/generated";

export function Catalog() {
  return (
    <ul>
      {allProducts.map((p) => (
        <li key={p.sku}>
          {p.name} — {p.price}
        </li>
      ))}
    </ul>
  );
}

// Detail route — O(1) map lookup (no getter in list-only mode)
productBySku["W-100"]?.price;

// Category landing page
productsByCategory.find((g) => g.key === "widgets")?.items;

// Homepage strip
allFeaturedProducts.map((p) => p.name);
```

No getter is emitted in `list-only` mode — prefer `defineIndex` for detail routes. Full options: [defineView](/reference/define-view).
