---

```ts
import { assets, schema as a } from "@anhur/assets";
```

- `processors: [assets({ dir?, base?, storage? })]` — defaults `.anhur/assets` and `/anhur-assets/`
- Schema: `a.image()`, `a.file()`
- Rewrites relative URLs in MDX/Markdown bodies when those processors run
- Depends on `sharp`
- Optional **build-time CDN sync** via `storage` + [files-sdk](https://files-sdk.dev/) (S3, R2, MinIO, …)

Guide: [Assets](/guides/assets)
