Install only what your schemas (and search) need.

| Package                                 | Install when     | Provides                              |
| --------------------------------------- | ---------------- | ------------------------------------- |
| [`@anhur/core`](/packages/core)         | Always           | Config, schemas, CLI, integrations    |
| [`@anhur/vite`](/packages/vite)         | Vite apps        | Plugin + `anhur/generated`            |
| [`@anhur/mdx`](/packages/mdx)           | MDX bodies       | `mdx()` + `m.mdx()` + React           |
| [`@anhur/markdown`](/packages/markdown) | Markdown→HTML    | `markdown()` + `md.markdown()`        |
| [`@anhur/assets`](/packages/assets)     | Images/files     | `assets()` + `a.image()` / `a.file()`; optional CDN via `storage` |
| [`@anhur/orama`](/packages/orama)       | Full-text search | `orama()` + `createSearcher`          |

```package-install
@anhur/core @anhur/vite
```

```package-install
@anhur/mdx @anhur/markdown @anhur/assets
```

```package-install
@anhur/orama
```

Rule: every schema helper from an opt-in package needs its processor in `processors`. See [Processors](/concepts/processors). Search uses `integrations`, not processors — see [Integrations](/concepts/integrations) and [Search](/guides/search).
