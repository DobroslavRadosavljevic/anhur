Vite integration for any Vite app.

## Install

```package-install
@anhur/core @anhur/vite
```

## Usage

```ts
import anhur from "@anhur/vite";

export default defineConfig({
  plugins: [anhur()],
});
```

## What it does

1. Resolves `anhur.config.ts`
2. Aliases `anhur/generated` → `.anhur/generated`
3. Builds on `buildStart`; watches in dev
4. Serves asset files when `@anhur/assets` is configured
5. Skips copying assets into the Vite outDir when remote CDN storage is enabled

Full guide: [Vite plugin](/guides/vite-plugin) · [Vite setup](/getting-started/vite)
