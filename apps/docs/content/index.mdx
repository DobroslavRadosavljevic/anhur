**Anhur** reads Markdown, MDX, YAML, and JSON from folders you control, validates each file against schemas you write, and generates TypeScript modules you import like any other code.

No hosted CMS. No hand-rolled front-matter parsers in every route. Content lives in git next to the app.

:::note
APIs may still change before 1.0. Treat this as early docs and pin versions carefully.
:::

## What you get

- **Typed imports** — `import { allPosts, getPost } from "anhur/generated"`
- **Light lists** — indexes omit heavy fields (default: `body`) so listing pages stay cheap
- **On-demand documents** — `getPost(...)` loads one full document when you need it
- **Derived views** — `defineView` / `defineIndex` / `defineGroup` for featured lists, SKU maps, and category groups
- **Folder locales** — `content/posts/en/…` and `content/posts/de/…` when you want i18n
- **Opt-in processors** — MDX, Markdown→HTML, and assets via separate packages

## When it fits

| Good fit                                 | Weaker fit (today)                         |
| ---------------------------------------- | ------------------------------------------ |
| Blogs, docs, changelogs, marketing pages | Remote CMS as the source of truth          |
| Product catalogs in JSON/YAML            | Official Next.js adapter (use CLI + alias) |
| Directories with facet / SEO landings    | Non-Zod schema libraries                   |
| Multi-locale sites with folder layout    | Field-level (not folder) translation       |
