A typical Vite app looks like this:

```txt
my-app/
  anhur.config.ts
  vite.config.ts
  tsconfig.json
  content/
    posts/
      en/
        hello.mdx
      de/
        hello.mdx
    authors/
      ada.yml
  src/
    ...
  .anhur/
    generated/     # typed modules (anhur/generated)
    assets/        # copied files when using @anhur/assets
    cache/         # build cache (safe to delete)
```

## Config location

Put `anhur.config.ts` at the Vite project root, or pass `anhur({ configPath: "…" })` to the plugin. All relative paths in the config are resolved from the **config file’s directory**.

## Generated output

Default output: `.anhur/generated`. Override with `outputDir` in `defineConfig` when you need a different location.

Import as:

```ts
import { allPosts, getPost } from "anhur/generated";
```

## TypeScript

```json
{
  "include": ["src", ".anhur/generated"],
  "compilerOptions": {
    "paths": {
      "anhur/generated": ["./.anhur/generated"]
    }
  }
}
```

## Gitignore

```gitignore
.anhur/cache
```

Teams usually either:

- **Ignore** `.anhur/generated` and `.anhur/assets`, and generate them in `vite build` / CI, or
- **Commit** generated output so typecheck works without a prior Anhur build

Both are valid. Pick one and stick to it.

## Engines

Packages target Node `^22.18.0` or `>=24.11.0`.
